# 🚀 AI Resume Analyzer (LLM-Based)

## 📌 Project Overview
AI Resume Analyzer is a smart web application that analyzes resumes using Large Language Models (LLMs). It evaluates resume quality, extracts skills, and matches candidates with job descriptions.

---

## 🎯 Features
- ✅ Resume Score (ATS-based scoring)
- ✅ Skill Extraction (from resume text)
- ✅ Job Matching (compare resume with job description)
- ✅ Suggestions for improvement
- ✅ Prompt Engineering for structured output

---

## 🧠 Tech Stack
- Python
- OpenAI API
- Pandas
- Streamlit (UI)
- NLP Techniques

---

## ⚙️ How It Works
1. Upload Resume (PDF/Text)
2. Extract text using NLP
3. Send data to LLM via API
4. Generate:
   - Score
   - Skills
   - Suggestions
5. Display results in UI
